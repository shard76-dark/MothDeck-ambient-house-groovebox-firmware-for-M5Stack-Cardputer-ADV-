M5Stack Cardputer ADV · ESP32-S3

MothDeck

Ambient-house groovebox firmware for the M5Stack Cardputer ADV. Drums, FX, a mixer, SD kits and loops, and BLE MIDI, on the board you already have.

Use earphones or headphones. Plug them into the 3.5 mm jack. This firmware does not play through the Cardputer ADV internal speaker. Unplugging the earphones does not switch the sound to the speaker.

Source on GitHub Flash / install Application image

Features

  • Ambient house drums Twelve hits at the recorded pitch: kick, rim, snare, clap, hats, toms, shaker, ride, snap, crash. Octave does not transpose the kit.
  • Groovebox Four tracks. Each pattern is 1–8 bars of 16th notes (16–128 steps, four steps per beat). The 256-step grid holds four patterns up to four bars, and two patterns at eight bars.
  • FX and mixer Per-track filter, delay, reverb, bitcrush, drive, chorus, and tremolo. Mixer faders with mute and solo.
  • SD kits and loops Load kits from the card onto Drums. Loops stream in short windows instead of filling RAM.
  • Piano roll Play opens on a roll. Time runs across, keys down the left, and a note is a block 1–4 steps long. Enter returns to the 16-step strip. Patterns are still 1–8 bars.
  • BLE MIDI Off until Settings turns it on. The air name is Mothdeck. Notes on channels 1–4 play the four tracks. Clock, Start, Continue, Stop, and Song Position follow an MPC. Forget an old MothDeck bond on the MPC before pairing this name.
  • SD patches A folder can be a patch of a sound that already exists, with scale, a held arp, a second oscillator, and glide. Enter on the Instrument page assigns it.
  • Lean samples Unsigned 8-bit mono at 22050 Hz, about 22 KB/s. The mix stays 44100 Hz.

Flash it

Earphones or headphones required. The internal speaker on the Cardputer ADV does not work with this firmware. Listen on the 3.5 mm jack.

Install mothdeck-cardputer-adv.bin from Launcher. The full button sequence is in releases/INSTALL.md.

  1. Copy the application image (the file that starts with E9) to a FAT32 microSD card. Do not install the full-flash image from Launcher.
  2. Boot Launcher, press Enter on its splash, open the SD browser, and install that file.
  3. The next boot that follows the boot selection starts MothDeck: backlight, a one-second amber moth, then Play.

Unzip mothdeck-sd-pack.zip onto the card root when you want the extra kits, loops, and plugin instruments. Checksums are in SHA256SUMS.

On the keyboard

Tab moves through Play, Instrument, FX, Mixer, Song, Loops, MIDI, Settings, and Exit. On the Instrument page, comma and slash load the previous and next drum kit from /moth/drums. Hold Esc (the grave key) or the front button for about 0.7 seconds to return to Launcher, and only when a real Launcher image is present.

Key drawings: Play, Instrument, FX, Mixer, Song, Loops, MIDI, Settings, Exit. File layouts are in FORMATS.md.
